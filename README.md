# Damián Bender — Portfolio

Portfolio de **desarrollo web e implementación digital**. Presenta una selección de proyectos reales y explica las soluciones técnicas implementadas: formularios personalizados, embudos, automatizaciones, experiencias interactivas y aplicaciones web.

## Enfoque

Parto de necesidades concretas para definir requerimientos, construir soluciones funcionales y verificar la entrega. Los casos ilustran capacidades de implementación; no se atribuyen resultados comerciales que no estén documentados.

## Proyectos destacados

- **Test de perfiles — Enfoca Tu Ser:** cuestionario personalizado, validación de respuestas, datos de contacto en Systeme.io y secuencias automatizadas por perfil.
- **Experiencia interactiva — Growing Business School:** actividad que invita a identificar errores en respuestas simuladas de IA.
- **Taller y guía — Growing Business School:** página comercial con temporizador contextual, propuesta de captación y recurso informativo de 25 tareas para médicos.
- **Aplicación web para cliente:** ejemplo conceptual de desarrollo a medida, sin compartir código ni información privada del proyecto.

Algunas funcionalidades de los proyectos externos pueden no estar disponibles temporalmente por depender de servicios gestionados por terceros.

## Implementación

Portfolio estático, responsive y accesible, realizado con HTML, CSS y JavaScript. Incluye un visor de capturas que permite ampliar diagramas técnicos sin perder legibilidad.

- `index.html`: contenido y casos de estudio.
- `styles.css`: estilos y diseño adaptable.
- `script.js`: navegación del visor y comportamiento de la interfaz.
- `media/`: capturas reales seleccionadas para presentación pública.
