# Portfolio de Damián Bender

Sitio estático, adaptable a celulares y pantallas grandes. No necesita instalación de paquetes ni base de datos.

## Ejecutar localmente

Abrí `index.html` en el navegador o ejecutá `python -m http.server 8000` desde esta carpeta.

## Publicar en Vercel

1. Subí los archivos a tu repositorio `metodoprisma-db/porfolio-DamianBender`.
2. En Vercel elegí **Add New > Project > Import Git Repository**.
3. Framework preset: **Other**. Root directory: `./`.
4. No hace falta configurar un comando de build. Publicá.

## Qué incluye

- Página principal con posicionamiento orientado a implementación.
- Cuatro casos reales, con descripciones basadas en los trabajos contados por Damián.
- Dos capturas reales del test y de la automatización de Systeme.io.
- Visor con controles para acercar, alejar y desplazarse por capturas grandes.
- Secciones de servicios, metodología de trabajo y contacto.

## Pendiente antes de enviar a clientes

- Completar un enlace de contacto directo (no se inventó WhatsApp ni correo).
- Reemplazar las ilustraciones esquemáticas por capturas reales cuando estén disponibles.
- Confirmar que existe autorización para mostrar material de clientes.
- Incorporar el enlace o capturas de la página del taller, los videos y la aplicación en desarrollo.

Las imágenes del test y del diagrama están en `media/`, sin edición destructiva. El diagrama se puede ampliar al tamaño original desde el visor.
